# IZON Apparel — Website

A complete seven-page, responsive, cinematic/corporate static website concept built using HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Homepage, interactive manufacturing explorer
- `about.html` — Founders' stories, vision and mission
- `capabilities.html` — Manufacturing workflow
- `infrastructure.html` — Facility showcase
- `products.html` — Knitted and basic woven apparel categories
- `sustainability.html` — Responsible manufacturing commitments
- `contact.html` — Contact details and email enquiry composer

## Run locally
Open `index.html` in a browser, or for more consistent behaviour run a local server from the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish at low cost
1. Create a GitHub repository and upload the **contents** of this folder.
2. In repository **Settings → Pages**, choose deployment from the `main` branch and root folder.
3. GitHub Pages will give you a public preview URL.
4. Add a custom domain in GitHub Pages settings after domain ownership and DNS are configured.

Alternative: import the repository into Cloudflare Pages or Netlify.

## Before a real company launch — required
- **Replace brochure-derived crops** with licensed, high-quality real IZON facility photos and short videos. The existing images were extracted from the supplied nine-page profile and are **temporary**.
- Replace the typographic nav mark with the company-approved **original vector logo**.
- Reconfirm the company address, phone, email, machine count and monthly production capacity.
- Confirm public use of the founder stories and any business claims.
- Obtain precise product categories, technical capabilities and authentic product photographs.
- Verify sustainability claims, certifications and any compliance statements before publishing.
- The contact form **opens an email client** and does not submit on its own. To accept enquiries directly from the webpage, integrate a trusted form backend, set up domain email, spam protection, delivery logging and privacy terms.
- Add legal privacy policy/cookie notices if collecting visitor data or installing analytics.
- Finish accessibility checks, cross-browser testing, Lighthouse performance review, and final mobile QA.
- Add site URL, verified structured data, sitemap, robots.txt and analytics after the actual domain is confirmed.

## Interaction highlights
Responsive menu, page-load intro, scroll progress, editorial text reveals, homepage parallax, tab-switching manufacturing explorer, fluid hover interactions, and reduced-motion support. No framework or paid animation dependencies are required.

## High-resolution imagery update (November 2026)

The site includes enhanced high-resolution photographs extracted from the IZON-supplied company profile. Main cinematic backgrounds are provided at up to 3840 × 2160 pixels; smaller photographs have been enhanced for sharper large-screen presentation. **These are upscaled versions of the supplied photos, not native 4K photographs**, so they cannot recover detail that was absent from the originals. For a truly sharp 4K production launch, replace these files with original 4K photographs of IZON facilities. The files are hosted inside `assets/` and do not require external image services.
